## ✨ Features

- **🪟 Advanced Window Management:** Fully draggable, resizable, and stackable windows with smart Z-index sorting powered by Zustand and GSAP.
- **🌐 Functional Safari Browser:** Real Google Search integration with an authentic macOS address bar, loading states, and frosted glass effects.
- **💻 Interactive Terminal:** Simulated ZSH terminal with a mock file system and commands (`ls`, `cd`, `pwd`, `echo`, `clear`, `open`).
- **🔍 Spotlight Search:** Press the search icon to instantly search and launch available applications.
- **📱 Simulated Apps:** Includes Finder, Photos, Contacts, Trash, and a PDF viewer (Resume).
- **🖱️ Authentic Interactions:** Hover-to-expand menu bars, interactive traffic-light window controls, and a magnifying dock.
- **🚀 Boot Sequence:** Realistic black-screen Apple boot-up animation that preloads assets.

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand) (Immer integrated)
- **Animations:** [GSAP](https://gsap.com/) & GSAP Draggable
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/) (io5, bs)
- **Date Handling:** [Day.js](https://day.js.org/)
